# Product Definition: GCCli

## Vision
A powerful, local-first, multi-model CLI agent with deep skills integration and proactive behavior. GCCli brings the power of Grok and other LLMs directly to the terminal with state persistence and tool-calling capabilities.

## Core Features
- **Multi-Model Routing:** Pluggable providers (xAI/Grok, fallback support).
- **Core System Skills:** Proactive behavior, Teleportation (state export/import).
- **Persistent Memory:** Session context maintained across restarts.
- **Dynamic Tooling:** Registry for agent functions and slash commands.

## Target Audience
- Developers who want an AI-augmented terminal experience.
- Power users needing cross-session agent continuity.
